This component of the monitoring system is developed to process real-time sensor readings. The system reads temperature ($^\circ\text{C}$) and turbidity ($\text{NTU}$) levels, calculates a Water-Quality Index (WQI), and classifies the water status as Good, Warning, or Critical.

Run with: gcc question1/question1.c -o question1/question1 && ./question1/question1
